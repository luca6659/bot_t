# Бот для продажи 3D-игрушек

Telegram-бот на TypeScript и grammY: каталог и поиск, корзина, своя модель, счета и чеки, статусы заказа, анонимная переписка с покупателем и админка прямо в Telegram.

## Подготовка в Telegram

1. В [@BotFather](https://t.me/BotFather) создать бота командой `/newbot` и сохранить токен.
2. Создать группу для админов и включить в её настройках **Темы** (Topics).
3. Добавить бота в группу и сделать администратором с правом **управлять темами**.
4. Написать в группе `/chatid`: бот пришлёт ID группы.

## Запуск на своём компьютере

Нужен Node.js 22 или новее. База поднимается сама в папке `.data`, бот работает через long polling.

```bash
npm install
cp .env.example .env
```

В `.env` заполнить `BOT_TOKEN` и `ADMIN_GROUP_ID`, затем:

```bash
npm run dev
```

## Запуск в облаке

Подойдёт любая платформа с Node.js или Docker (Railway, Timeweb Cloud Apps и т.п.) и база PostgreSQL (например, Neon). В проекте есть `Dockerfile`.

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | токен бота |
| `ADMIN_GROUP_ID` | ID группы админов |
| `DATABASE_URL` | адрес PostgreSQL |
| `WEBHOOK_URL` | публичный адрес сервиса, например `https://bot.example.com` |
| `WEBHOOK_SECRET` | длинная случайная строка из букв и цифр |
| `NODE_ENV` | `production` (в Dockerfile уже задано) |

Таблицы создаются при старте. Проверка работы: `GET /healthz`. Запускать нужно **один экземпляр**: очередь апдейтов и лимиты хранятся в его памяти.

## Первая настройка

В группе написать `/admin`, затем:

1. **Тексты → Реквизиты для оплаты.** Пока их нет, бот предупреждает админов в теме заказа.
2. **Тексты → Адрес и часы самовывоза.**
3. **Тексты → Курьер.** Единая цена доставки или `-`, чтобы считать её вручную для каждого заказа.
4. **Категории**, затем **Товары**: фото, цена, размеры и цвета.

## Как идёт заказ

`Новый → Ждёт оплаты → Чек на проверке → Оплачен → В печати → Готов → У курьера → Выполнен`, отменить можно на любом шаге до выполнения.

- Покупатель получает уведомление о каждом статусе, кроме «Новый».
- «Новый» означает одно из двух: своя модель ждёт оценки или курьерская доставка ждёт расчёта. При самовывозе и при единой цене курьера счёт уходит сразу.
- Статус меняется кнопками под карточкой заказа в теме покупателя.

## Переписка

Всё, что покупатель пишет боту вне диалогов, приходит в его тему. Обычное сообщение админа в этой теме бот копирует покупателю от своего имени, поэтому автора покупатель не видит. **Любое сообщение в теме уходит покупателю**, кроме команд и ввода, который бот сам запросил. Обсуждать заказ между собой лучше в теме General.

## Разработка

```bash
npm test
npm run typecheck
```

Тесты проходят все сценарии на настоящем коде бота и встроенном Postgres, вместо Telegram работает имитация, которая проверяет его ограничения (разметка, длина текста, размер данных кнопки).

Структура: `src/modules/*` разбит по доменам, внутри слои Handler → Service → Repository. Сборка всех частей находится в `src/bot/create-bot.ts`, запуск в `src/app.ts`, тексты в `src/i18n/texts.ts`.
